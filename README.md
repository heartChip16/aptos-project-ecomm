APTOS Project

Ecommerce app with Aptos Wallet Selector and can pay Aptos coins from Wallet during Checkout. 

Finished the project. User logs in (though this is not fully implemented in the sense that when reloaded will logout user, so just for prototype, using Firebase)

After logging in, the user adds to cart. User must make sure to connect to the Petra Wallet. Can use testnet. It must have balance. For a successful transaction, the petra wallet must have sufficient balance more than the amount to spend from the cart. 

NOTE: User must select payment method as Crypto to pay Aptos coins. (though TESTNET for now).
